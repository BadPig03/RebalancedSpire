v0.3.12-beta Version Update Announcement
[blue]Compatible with [b]Beta v0.113.0[/b] and [b]RitsuLib 0.6.11[/b][/blue]

[blue][b]Content:[/b][/blue]

[b]Enemies[/b]
- Added a unique Dominion effect for [b]Doormaker[/b]:
  - At the start of each non-Boss combat, each player gains 4 Scrutiny.
  - Each stack of Scrutiny reduces your maximum hand size by 1. Lose 2 Scrutiny at the end of your turn.

[blue][b]Bug Fixes:[/b][/blue]

- Fixed an issue where the changes to Neow's relic choices overrode the starting rewards in Blitz mode.
- Fixed an issue where Orobas and Darv could offer relics banned in the current game mode.
- Fixed an issue where the ending text for some Ancient events did not display correctly.
- Fixed an issue where enabling Vakuu's artwork fix could prevent the background from displaying correctly.
- Fixed an issue where the Doormaker encounter's scene failed to load.
- Fixed an issue where the card art for Corpse Explosion and Limit Break was missing.
- Fixed an issue where Expect a Fight's hover tips could affect other cards.
- Fixed an issue where Ceremonial Beast did not gain Strength correctly after using Plow.
- Fixed issues where Thieving Hopper could steal Quest cards or stop stealing cards early in multiplayer.
- Fixed an issue where Gas Bomb's death could be processed twice if it died while exploding.
- Fixed an issue where Fishing Rod still displayed the modified effect description after its changes were disabled.
- Fixed an issue where some enemy move names did not display correctly.
- Fixed incorrect descriptions for some configuration options and Scrutiny.
