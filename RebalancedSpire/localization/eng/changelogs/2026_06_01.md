v0.2.1-beta Version Update Announcement
[blue]Compatible with [b]Beta v0.106.1[/b] and [b]RitsuLib 0.3.10[/b][/blue]

[blue][b]Content:[/b][/blue]

[b]Enemies[/b]
- Buffed enemy [b]Inklet[/b]: Piercing Gaze deals 1 more damage.
- Buffed enemy [b]Seapunk[/b]: Sea Kick deals 1 more damage.
- Buffed enemy [b]Sludge Spinner[/b]: Slam deals 1 more damage.
- Buffed enemy [b]Gremlin Merc[/b]: Double Smash's base damage increased by 1.
- Adjusted elite [b]Soul Nexus[/b]:
  - Soul Mark now applies 99 Vulnerable instead of 1.
  - The Soul Decay status effect now also counts damage dealt to Osty, and in multiplayer, its counter is tracked independently for each player.
- Adjusted Boss [b]Aeonglass[/b]:
  - Playing an unupgraded Wither now increases its cost by 1.

[blue][b]Bug Fixes:[/b][/blue]

- Fixed an issue where disabling the Kin Squad encounter in the config options could cause the game to error.
- Fixed an issue where Doormaker could still appear after being disabled in the config options.
- Fixed an issue where config options could still be changed outside the title screen.
- Fixed an issue where upgraded Master Planner did not correctly increase its stack count when played.
- Fixed an issue where Wither's No Escape description was missing.
